Synchroniser avec l'agenda de votre téléphone

Abonnez-vous une seule fois : toutes vos interventions (avec client, adresse et téléphone) et vos jours bloqués apparaissent dans le calendrier du téléphone et se mettent à jour automatiquement. Lien secret : ne le partagez pas.

S'abonner

iPhone : « S'abonner » ouvre directement le calendrier (ou Réglages → Calendrier → Comptes → Ajouter un compte → Autre → Ajouter un cal. avec abonnement, puis coller le lien).
Google Agenda : sur ordinateur, Autres agendas → + → À partir de l'URL, puis coller le lien ; il apparaît ensuite sur le téléphone Android.

Jours bloqués : ils apparaissent immédiatement comme indisponibles dans le calendrier de prise de rendez-vous du site.
